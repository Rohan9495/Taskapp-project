# TaskBuddy ✅

TaskBuddy is a modern, beautifully designed Task Management application built with React and Vite. Stay organized, focused, and productive with a sleek glassmorphism user interface.

## ✨ Features

- **Add & Track Tasks:** Easily add new tasks to your list.
- **Edit Tasks:** Double-click on any task (or click the edit button) to update it in place.
- **Delete Tasks:** Remove tasks you no longer need.
- **Completion Tracking:** Check off tasks as you complete them.
- **Filtering:** Filter your tasks by "All", "Active", and "Completed".
- **Persistent Storage:** All tasks are automatically saved to your browser's local storage, ensuring you never lose track of your to-dos.
- **Modern UI:** A stunning dark-mode glassmorphic design that looks great on any screen.

## 🚀 Technologies Used

- [React](https://reactjs.org/) (Hooks: `useState`, `useEffect`)
- [Vite](https://vitejs.dev/)
- [UUID](https://www.npmjs.com/package/uuid) for unique identifiers
- Pure CSS (Glassmorphism & Flexbox)

## 🛠️ Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

- Node.js (v14 or higher)
- npm (or yarn)

### Installation

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/Rohan9495/Taskapp-project.git
   cd Taskapp-project
   ```

2. **Install the dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open the app:**
   Open your browser and navigate to `http://localhost:5173` (or the port specified in your terminal).

## 📂 Project Structure

- `src/App.jsx` - Contains the main React logic, state management, and structure.
- `src/App.css` - Contains the styling, including the custom glassmorphism effects.
- `src/main.jsx` - The entry point of the React application.
